Git — это программа и распределенная система контроля версий, которая работает на вашем компьютере и отслеживает историю изменений в коде.
А GitHub — это онлайн-сервис и облачная платформа для хранения таких проектов и удобной совместной работы над ними.


До выполнения
git add Когда вы отредактировали код, но еще ничего не добавляли в индекс
Команда git diff сравнивает ваш рабочий каталог (код, который вы прямо сейчас меняете) с индексом (состоянием на момент последнего коммита или предыдущего add).Она покажет все ваши свежие, еще не сохраненные изменения.
Команда git diff --staged в этот момент покажет пустой результат (если только вы не добавили другие файлы ранее), так как в индексе еще нет новых изменений для сравнения с прошлым коммитом.

После выполнения
git add
Когда вы выполнили команду git add . (или указали конкретный файл) и «подготовили» изменения:
Команда git diff теперь покажет пустой результат. Так происходит потому, что вы перенесли изменения из рабочего каталога в индекс, и теперь эти два состояния абсолютно идентичны.
Команда git diff --staged покажет все ваши изменения. Теперь она сравнивает подготовленный индекс с вашим последним коммитом (HEAD), позволяя проверить, что именно попадет в финальный коммит.







«Использованные команды»:
git status показывает текущее состояние вашего репозитория. Она выводит список измененных, подготовленных к коммиту и неотслеживаемых файлов, помогая понять, на каком этапе работы вы находитесь.
git diff показывает конкретные строки кода, которые вы изменили, сравнивая файлы в вашем рабочем каталоге с индексом (Staging Area). Она отображает всё, что еще не было добавлено через git add.
git diff --staged показывает изменения, которые вы уже подготовили к сохранению. Она сравнивает индекс с вашим последним коммитом и демонстрирует, что именно попадет в историю, если вы прямо сейчас выполните git commit.




«Ветки»:
Ветка (Branch) — это просто подвижный указатель на один из коммитов в истории проекта (по сути, именованная ссылка на конкретный снимок кода).
При новом коммите создается новый снимок проекта, а указатель текущей ветки автоматически перемещается вперед, начиная указывать на этот только что созданный коммит.
Слияние (Merge) объединяет историю двух разных веток, перенося изменения из одной ветки в другую (обычно целевую) и создавая при необходимости специальный коммит слияния (merge commit).

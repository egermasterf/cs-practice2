git diff — показывает построчную разницу между рабочей директорией, индексом и коммитами.

git show — выводит содержимое одного коммита вместе с его изменениями относительно родителя.

git log — выводит список коммитов в обратном хронологическом порядке.

git log -S "строка" — находит коммиты, в которых изменилось число вхождений указанной строки.

git blame файл — показывает для каждой строки файла коммит, автора и дату последнего изменения этой строки.
